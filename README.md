# Data Cleaning Portfolio Case

Small portfolio project demonstrating a reproducible workflow for cleaning and validating spreadsheet data with Python and Pandas.

## Repository structure

```text
data-cleaning-portfolio/
├── README.md
├── .gitignore
├── data/
│   ├── raw/
│   │   └── pedidos_sujos.xlsx
│   └── processed/
│       └── .gitkeep
├── notebooks/
│   └── 01_data_cleaning.ipynb
└── assets/
    └── .gitkeep
```

## Case objective

Transform an intentionally inconsistent order spreadsheet into a clean, validated and reusable dataset.

The raw file contains realistic quality problems such as duplicated records, missing values, inconsistent text categories, mixed date formats, numeric values stored as text, extra whitespace and invalid values.

## Deliverables

- Reproducible Jupyter Notebook
- Clean `.xlsx` output
- Short summary of data-quality issues found and corrected
- Optional before/after screenshots for freelance-platform portfolios

## Tools

Python · Pandas · Jupyter Notebook · XLSX
